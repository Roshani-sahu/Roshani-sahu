## 🛠️ My Engineering Approach

I care about more than just making a page look good.

**01 — Build reusable UI**

Create modular React components instead of repeating UI logic.

**02 — Keep interfaces responsive**

Design for different screen sizes and real-world usage.

**03 — Connect the frontend properly**

Integrate REST APIs through structured service layers and Axios-based clients.

**04 — Think about maintainability**

Prefer readable TypeScript, predictable component architecture, and reusable utilities.

**05 — Keep learning**

I'm continuously expanding from frontend engineering toward stronger **MERN and full-stack development**.
